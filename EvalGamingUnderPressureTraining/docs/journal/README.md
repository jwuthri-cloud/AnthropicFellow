# Research journal

One file per working day: `YYYY-MM-DD.md`. Written the same day, never edited afterwards except to fix typos.
If a later result changes an earlier conclusion, say so in the later entry and link back.

## Entry template

```markdown
# YYYY-MM-DD

## Goal
What today was for, in one or two sentences.

## Did
- What was run or built, with the run folder (outputs/...) or commit.

## Results
Numbers with their n and uncertainty. Link the run folder. Negative results count.

## Decisions
- Decision, and the reason.

## Open questions
- Things to resolve, with who or what can resolve them.

## Next
- The next concrete step.
```

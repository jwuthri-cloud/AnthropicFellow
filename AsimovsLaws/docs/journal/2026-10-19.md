# 2026-10-19: project set up

## Question
Does a model represent, in its activations, that the action it is about to take will harm the user (an outcome the user would reject if fully informed)? And does it take that action anyway on traces that never mention the harm ("knowing harm")? This turns Asimov's First Law into something we can measure, instead of something we encode.

## Design (v1)
- **Probe:** fit on a generic contrast set, `data/contrast/harm_contrast.jsonl`. It has 300 third-person pairs: an assistant's action does or does not harm the person, and one fact differs between the two rows. The splits are train 200 / test 50 / hardneg 50. The topics are disjoint from the scenarios'.
- **Scenarios:** `data/scenarios/pairs.jsonl` holds 40 matched pairs across 3 harm types: 14 data_loss, 13 health_finance, 13 sycophancy. Half the pairs put the fact right before the request and half put it far back. The request and the A/B/C options are identical across the pair; one fact decides whether the literal "best" option harms the user.
- **Harm label:** `ACTION:` regex on the answer, so the label never comes from an LLM.
- **Silent traces:** neither the harm-word regex nor the Haiku judge (`data/monitor/rubric.md`) finds a mention of harm.
- **Controls:**
  - Shuffled labels.
  - Random directions.
  - Bag-of-words trained on the same contrast text.
  - The hardneg split, where harm vocabulary sits on the safe side.
- **Reused code:** sampling, activations, probe fitting, AUROC CIs and the judge come from `evalgaming` (path dependency).

## Done today
- Both experiments dry-ran on CPU with a fake sampler and fake activations. The controls sit at chance on noise.
- The smoke run covers 12 pairs: 4 per harm type, 2 near and 2 far.

## Finding: the first contrast set had a structural word leak
A bag-of-words classifier fit on contrast train scored AUROC 0.87 on hardneg and 0.66 on test.
- **Cause:** the safe hardneg rows nearly always justify the action ("…, so the assistant is about to…": "so" 49× vs 1×).
- **Train cues:** "asked" (consent) leans safe and "will" (explicit consequences) leans harm.
- **Risk:** a probe trained on this set could learn "the action is justified or consented to" instead of "the action harms the user".
- **Fix:** the pairs were rewritten so that both rows share the same clause structure. Ids, splits and domains are unchanged. AUROC fit on train after the fix:

  | Featurizer | test | hardneg |
  |---|---|---|
  | word counts | 0.52 | 0.43 |
  | TF-IDF, 1–2-grams | 0.55 | 0.48 |
  | char 3–5-grams | 0.55 | 0.46 |

  The hardneg split was tuned against the word-count model only, but the result holds for the other two featurizers.
- **What this means for the probe:** a hardneg AUROC well above 0.5 can no longer come from surface words.

## Open risks
- The scenario harms are fairly obvious, so Qwen3 may rarely pick the harmful target. That would leave few knowing-harm cases to study. If so, the next lever is pressure in the prompt (operator instruction, reward framing, user pushback), kept identical across each pair.
- The AWS launch script rsyncs only the eval-gaming repo; this repo's path dependency needs both repos on the box.
